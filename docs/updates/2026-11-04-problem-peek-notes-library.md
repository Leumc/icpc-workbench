# 笔记库 + 题目速览

针对两个反馈：

1. 记过笔记的题目很难找到 → 新增**笔记库**；
2. 点击题目直接跳到 OJ，事先看不到标签、难度，也看不到自己以前的笔记——尤其在 AI 给的题单里，除了 AI 的提示和题名什么都看不到 → **每一个**题目链接点击后先弹出**题目速览**，详细内容放在二级弹窗，二级弹窗可跳到对应功能页。

## 题目速览

### 触发：全局拦截，而不是逐页接入

`externalLinks.ts` 的 `setupExternalLinks` 原本只在桌面壳里接管外链；现在在浏览器与桌面壳里都于 document **捕获阶段**识别「指向题目页的 `<a>`」（`problemPeek.ts` 的 `isProblemUrl`，覆盖 CF / Gym / AtCoder / 洛谷 / 牛客 / 代码源 / 计蒜客 / 力扣 / QOJ / VJudge / DashOJ），阻止默认跳转并唤起速览。因此页面表格、训练计划 / 日历 / 今日训练任务、复习库、题单、赛事分析、模板例题，以及 AI 回复与笔记里 Markdown 渲染出的链接全部生效，以后新增的页面也不需要单独接。

- 站内已知题目 id 的链接可加 `data-problem-id`（题目管理表格已加），比按链接解析更准；
- 不拦截：比赛页 / 博客等非题目链接、站内路由、`data-peek="off"`（速览卡片自己的「打开题目」按钮）、`Ctrl` / `⌘` / `Shift` / `Alt` + 点击与中键；
- 速览卡片里再点别的题目链接（例如笔记里引用的题）会切换到那道题。

### 一级弹窗

题号、平台、难度（含平台原生档位）、知识点标签、做题状态（已通过 / 尝试未过 / 未提交）、镜像题提示、今日训练推荐记录，以及六行摘要：

| 行 | 摘要 | 二级弹窗内容 | 跳转 |
| --- | --- | --- | --- |
| 笔记 | 条数、最近更新、标注、最新一条开头 | 全部笔记（可写 / 编辑 / 删除）+ 复习笔记 | 笔记库（定位到该题） |
| 卡点 | 最近一次卡点与知识点 | 全部卡点记录 | 题目管理（按题号搜索） |
| 复习 | 档位、到期、复习次数；未加入时可一键「加入复习」 | 排期详情、复习笔记、全部复习日志 | 复习库 |
| 提交 | AC 次数、首次 AC | 判题分布 + 最近 100 次提交 | 题目管理 |
| 训练任务 | 所在计划、打卡数、**AI 提示** | 每个任务的类型、日期、打卡状态与完整提示/备注 | 训练计划 / 日历打卡 |
| 题单 | 所在题单与分类 | 全部题单条目 | 题单整理 |

数据按**原题身份**合并：在 Codeforces 链接上也能看到挂在洛谷 `CF1919C` 镜像上的笔记、卡点、复习与提交。题库里还没有的题（AI 计划里常见）仍按链接匹配训练任务（含任务上的笔记与提示）和题单，并可「加入复习」顺带登记题目。

接口：`GET /api/problems/peek?url=|id=|platform=&key=`（`server/src/problems/peek.ts`）。

### 细节

- 一级 `zIndex 1200`、二级 `1210`，在比赛分析弹窗、计划抽屉里点题目也能盖在最上层；
- 二级弹窗里点到另一道题时一级内容整体替换，焦点收回卡片，`Esc` 仍按层关闭；
- ≤640px 摘要行改为两行（标题 / 摘要），420px 宽实测无横向溢出。

## 笔记库（`/notes`，侧栏「题库」组）

- 按题归档：题目笔记、打卡笔记（经任务关联到题目的也算）与复习库里的复习笔记汇总成「一道题一张卡」；专题 / 模拟赛等无题目任务上的笔记按任务归档；
- 搜索题号、题名、笔记正文、任务与计划标题（`%`、`_` 按字面量匹配），按平台、标注（下拉带条数）、来源（题目笔记 / 复习笔记）筛选，按最近更新 / 笔记最多 / 题号排序；
- 右侧详情：题目链接（同样弹速览）、「题目速览」按钮、复习笔记（可就地编辑）、全部题目笔记（写 / 编辑 / 删除）；
- 深链：`/notes?problem=<id>`、`?task=<id>`、`?note=<id>`（滚动并高亮该条）；
- 题目管理的笔记抽屉新增「在笔记库中查看」。

接口：`GET /api/notes/library?q=&platform=&label=&source=`；`GET /api/notes?problemId=&mirrors=1` 连同镜像题笔记。

笔记的增删改面板抽成 `ProblemNotesPanel`，题目管理抽屉 / 笔记库 / 速览三处共用，行为一致。
